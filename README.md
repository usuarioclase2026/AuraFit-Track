# AuraFit Track 🏋️‍♂️

**Proyecto Intermodular - 2º DAM**

AuraFit Track es una plataforma SaaS (Software as a Service) basada en el stack MERN (MongoDB, Express, React, Node.js). 
Está diseñada para que los entrenadores personales y dietistas independientes puedan gestionar de forma integral a sus clientes.

## Estructura del proyecto
- `/frontend`: Contendrá la aplicación cliente desarrollada en React.
- `/backend`: Contendrá la API REST y la lógica de servidor en Node.js/Express.
- `/docs`: Contendrá la documentación técnica, diagramas y wireframes del proyecto.
